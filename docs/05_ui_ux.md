# LoveAtlas - UI/UX 設計

## 1. デザインコンセプト

**「物語が息づく地図」** - 地図を主役に、名セリフが場所に感情的な意味を付与する体験。温かみと知的好奇心を刺激するデザイン。

## 4. 主要画面の設計

### 4.1 ホーム画面 (地図ビュー)

**目的:** アプリのメイン画面。地図上のピンから名セリフを発見する。

**要素:**
- Leaflet 地図 (中心: 日本全体を俯瞰、ズームレベル5)
- マーカークラスター (ズームアウト時に数字付きクラスタ表示)
- 作品タイプ別に色分けされたピン
- ピンクリックでポップアップ表示
- サイドパネル (PC) / ボトムシート (モバイル) にセリフ一覧

**インタラクション:**
- 地図の移動・ズームでバウンディングボックスAPI自動呼び出し (300msデバウンス)
- ピンクリック → ポップアップ → 「詳細を見る」→ セリフ詳細ページ
- フィルター変更 → ピンの再描画

## 6. レスポンシブ対応

### ブレークポイント

| 名称 | 範囲 | 主なデバイス |
|------|------|------------|
| mobile | 0 - 767px | スマートフォン |
| tablet | 768px - 1023px | タブレット |
| desktop | 1024px以上 | PC |

### レスポンシブ方針

- **モバイルファースト**: CSSはモバイル基準で記述し、`min-width` メディアクエリで拡張
- **地図は常にメインコンテンツ**: どの画面サイズでも地図が主役
- **タッチ対応**: ボタンサイズは最低44x44px、タップターゲット間隔8px以上
