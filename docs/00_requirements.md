## 1. プロジェクト背景・目的

### 1.1 背景

映画やアニメの「聖地巡礼」が広く浸透する一方、作品と場所の関係を体系的に探索できるサービスは限られている。旅行計画時や現地訪問時に、その場所にまつわる作品の言葉を手軽に知る手段が求められている。

### 1.2 目的

地図上の場所と映画・アニメの名セリフを結びつけ、ユーザーが場所を通じて作品の世界に触れられる体験を提供する。コミュニティ駆動型のプラットフォームとして、ユーザー自身がコンテンツを投稿・キュレーションする仕組みを構築する。

### 1.3 ターゲットユーザー

| ユーザー層 | ニーズ |
|-----------|--------|
| 旅行好き | 旅先で新しい視点や発見を得たい |
| 映画・アニメファン | 好きな作品の聖地を巡りたい・共有したい |
| 聖地巡礼者 | 訪問記録を残し、他のファンと共有したい |
| カジュアルユーザー | 地図をブラウズして名言に出会いたい |

## 2. システム概要

### 2.1 システム名称

**LoveAtlas** - 地図 × 名セリフ コミュニティプラットフォーム

### 2.2 システム構成

| 項目 | 内容 |
|------|------|
| アプリ種別 | Webアプリケーション (レスポンシブ対応) |
| バックエンド | Laravel 11.x (PHP 8.2) |
| サーバー環境 | XAMPP (Apache + PHP 8.2 + MariaDB 10.4) |
| フロントエンド | Blade テンプレート + Vite + Vanilla JS |
| 地図サービス | Leaflet + OpenStreetMap |
| ジオコーディング | Nominatim API |
| 対応ブラウザ | Chrome, Firefox, Safari, Edge (最新2バージョン) |
| 対応デバイス | PC, タブレット, スマートフォン |

### 2.3 システム構成図

```
[ブラウザ] ──HTTP──> [Apache / Laravel 11.x (PHP 8.2)] ──Eloquent──> [MariaDB 10.4]
    │                     │
    │ Leaflet + Vite      │ Nominatim API
    ↓                     ↓
[OpenStreetMap]    [ジオコーディング]
```

| ID | 機能名 | 概要 | 優先度 |

| F-006 | ユーザー登録 | メールアドレス+パスワードによるアカウント作成 | 必須 |
| F-007 | ログイン/ログアウト | メール or ユーザー名+パスワードでの認証 | 必須 |
| F-008 | パスワードリセット | メールによるパスワード再設定 | 必須 |
| F-009 | セリフ投稿 | セリフ・作品・キャラクター・場所を紐付けて投稿 | 必須 |
| F-010 | セリフ閲覧 | セリフの詳細情報を表示するページ | 必須 |
| F-011 | セリフ編集/削除 | 投稿者自身によるセリフの編集・削除 | 必須 |
| F-012 | いいね | セリフへのいいね(トグル式) | 必須 |
| F-013 | お気に入り | セリフのブックマーク保存 | 必須 |
| F-014 | 訪問記録 | 場所を訪問済みとして記録 (日付・メモ・評価) | 必須 |
| F-015 | 検索 | セリフ・作品・場所の横断キーワード検索 | 必須 |
| F-016 | 作品ページ | 作品詳細と紐づくセリフの一覧表示 | 必須 |
| F-017 | 作品登録 | セリフ投稿時に新規作品を登録 | 必須 |
| F-018 | プロフィール | 自分の投稿・お気に入り・訪問記録の閲覧 | 必須 |
| F-019 | 公開プロフィール | 他ユーザーの投稿一覧の閲覧 | 必須 |
| F-020 | タグ機能 | セリフへのタグ付けとタグ別一覧表示 | 必須 |
| F-021 | Explore | 人気セリフ・新着セリフのブラウズページ | 必須 |
| F-022 | セリフ承認 | 管理者による投稿セリフの承認/拒否 | 必須 |
| F-023 | 通報機能 | 不適切なセリフの通報と管理者による処理 | 必須 |
| F-024 | 管理ダッシュボード | 統計情報・承認待ち・通報の管理画面 | 必須 |
| F-025 | ユーザー管理 | 管理者による権限変更・BAN処理 | 必須 |

### 3.2 機能詳細

#### F-001: 地図表示

| 項目 | 内容 |
|------|------|
| 概要 | Leaflet ライブラリでOpenStreetMapタイルを表示 |
| 初期表示 | 日本全体を俯瞰 (中心: 36.5°N, 138.0°E, ズーム: 5) |
| 操作 | ドラッグで移動、ホイール/ピンチでズーム |
| データ取得 | 地図の表示範囲が変わるたびにAPIを呼び出し (300msデバウンス) |

#### F-002: ピン表示

| 項目 | 内容 |
|------|------|
| 概要 | 承認済みセリフの場所にマーカーピンを表示 |
| 色分け | 映画=青, アニメ=赤, ドラマ=緑, 小説=紫, ゲーム=橙, その他=灰 |
| 情報 | ピンにカーソルを合わせると作品名をツールチップ表示 |

#### F-004: ポップアップ表示

| 項目 | 内容 |
|------|------|
| 表示内容 | セリフ冒頭 (50文字)、キャラクター名、作品名、いいね数 |
| アクション | 「詳細を見る」リンクでセリフ詳細ページへ遷移 |

#### F-006: ユーザー登録

| 項目 | 内容 |
|------|------|
| 入力項目 | ユーザー名, メールアドレス, パスワード, 表示名 |
| ユーザー名 | 3-50文字, 英数字+アンダースコア, 一意 |
| パスワード | 8文字以上, 英数字混在必須 |
| メール | 有効な形式, 一意 |
| 処理 | パスワードはbcryptでハッシュ化して保存 |

#### F-009: セリフ投稿

| 項目 | 内容 |
|------|------|
| 必須入力 | セリフ本文, 作品, 場所 (緯度経度) |
| 任意入力 | キャラクター名, シーン説明, 話数情報, タグ(最大10), 画像 |
| 作品選択 | オートコンプリート検索。未登録なら新規作成 |
| 場所選択 | 地図クリック or 住所検索 (Nominatim) で緯度経度を取得 |
| 承認フロー | 投稿後は「承認待ち」状態。管理者が承認すると地図上に公開 |

#### F-012: いいね

| 項目 | 内容 |
|------|------|
| 動作 | トグル式。クリックで追加、再クリックで解除 |
| 表示 | いいね数をリアルタイム更新 (非同期API) |
| 制約 | ログインユーザーのみ。1ユーザー1セリフにつき1回 |

#### F-014: 訪問記録

| 項目 | 内容 |
|------|------|
| 入力項目 | 訪問日 (必須), メモ (任意), 評価1-5 (任意), 写真 (任意) |
| 制約 | 同一ユーザー・同一場所・同一日の重複不可 |
| 表示 | プロフィール画面の訪問記録タブに一覧表示 |

#### F-015: 検索

| 項目 | 内容 |
|------|------|
| 検索対象 | セリフ本文, キャラクター名, 作品名, 場所名 |
| 検索方式 | FULLTEXT検索 (MariaDB) |
| フィルター | 検索タイプ (全て/セリフ/作品/場所) |
| 結果表示 | カテゴリ別にグループ化して表示 |

#### F-022: セリフ承認

| 項目 | 内容 |
|------|------|
| 対象 | status='pending' のセリフ |
| 操作 | 承認 (approved) → 地図上に公開 / 拒否 (rejected) → 非公開 |
| 権限 | admin, moderator ロールのみ |

## 4. 非機能要件

### 4.1 性能要件

| 項目 | 要件 |
|------|------|
| ページ読み込み | 初回3秒以内、2回目以降1秒以内 (3G回線除く) |
| API応答 | 200ms以内 (地図データAPI) |
| 同時接続 | 50ユーザー (XAMPP開発環境想定) |
| データ量 | セリフ10,000件、ユーザー1,000人まで (MVP) |

### 4.2 セキュリティ要件

| 項目 | 要件 |
|------|------|
| 認証 | Laravel Breeze + Sanctum。パスワードはbcryptハッシュ |
| SQLインジェクション | Eloquent ORM / クエリビルダによるパラメータバインド |
| XSS | Blade テンプレートの `{{ }}` 自動エスケープ。CSPヘッダー設定 |
| CSRF | Laravel 標準の CSRF トークン検証 (`@csrf`) |
| セッション | Laravel セッション管理。HttpOnly Cookie、暗号化 |
| ファイルアップロード | Laravel Storage + バリデーション、Intervention Image でリサイズ |
| レート制限 | Laravel RateLimiter (ログイン:5回/分、API:60回/分、投稿:10回/時) |
| ディレクトリ保護 | Laravel 標準 (public ディレクトリのみ公開) |

### 4.3 可用性要件

| 項目 | 要件 |
|------|------|
| 稼働時間 | 開発環境のため24/7稼働は不要 |
| バックアップ | DBの定期バックアップ (手動、週次) |
| エラーハンドリング | 適切なエラーページ表示 (404, 403, 500) |
| ロギング | アプリケーションログをファイル出力 |

### 4.4 ユーザビリティ要件

| 項目 | 要件 |
|------|------|
| レスポンシブ | PC・タブレット・スマートフォン対応 |
| ブラウザ | Chrome, Firefox, Safari, Edge (最新2バージョン) |
| タッチ操作 | ボタン最低44x44px、十分なタップ間隔 |
| 日本語対応 | UIは日本語。セリフデータは多言語対応可能な設計 |

### 4.5 保守性要件

| 項目 | 要件 |
|------|------|
| コード構成 | Laravel MVC + Service 層による責務分離 |
| 命名規則 | Laravel 規約 + PSR-12準拠 (PHP)、BEM (CSS) |
| バージョン管理 | Git |
| DB管理 | Laravel Migration / Seeder でスキーマ・データをコード管理 |
| ドキュメント | 本要件定義書、DB設計書、API仕様書を整備 |

## 5. データ要件

### 5.1 主要データエンティティ

| エンティティ | 説明 | 主要属性 |
|------------|------|---------|
| ユーザー (users) | アプリ利用者 | ユーザー名, メール, パスワード, 表示名, 権限 |
| 名セリフ (quotes) | 投稿される名セリフ | セリフ本文, キャラクター名, シーン説明, 承認状態 |
| 作品 (works) | 映画・アニメ等の作品 | 作品名, 種別, 公開年, 国 |
| 場所 (locations) | セリフに紐づく地理情報 | 場所名, 緯度, 経度, 住所 |
| タグ (tags) | セリフの分類用タグ | タグ名, カテゴリ |
| お気に入り (favorites) | ユーザーのブックマーク | ユーザーID, セリフID |
| 訪問記録 (visits) | 場所の訪問記録 | ユーザーID, 場所ID, 訪問日, 評価 |
| いいね (votes) | セリフへのいいね | ユーザーID, セリフID |
| 通報 (reports) | 不適切コンテンツの通報 | 通報者, セリフID, 理由, 処理状態 |

### 5.2 データ間の関係

```
users ──1:N──> quotes      (ユーザーがセリフを投稿)
works ──1:N──> quotes      (作品にセリフが紐づく)
locations ──1:N──> quotes  (場所にセリフが紐づく)
users ──1:N──> favorites   (ユーザーがお気に入り登録)
users ──1:N──> visits      (ユーザーが訪問記録)
users ──1:N──> votes       (ユーザーがいいね)
quotes <──N:M──> tags      (セリフとタグの多対多)
```

### 5.3 初期データ

MVPリリース時にサービスが空にならないよう、以下の初期データを投入する。

| カテゴリ | 件数目安 | 例 |
|---------|---------|-----|
| ジブリ映画 | 5-10作品, 15-30セリフ | 千と千尋の神隠し(道後温泉), もののけ姫(屋久島) |
| 新海誠作品 | 3-5作品, 10-15セリフ | 君の名は。(飛騨/須賀神社), 天気の子(田端駅) |
| 有名映画 | 5-10作品, 10-20セリフ | ローマの休日(スペイン広場), アメリ(モンマルトル) |
| アニメ聖地 | 5-10作品, 10-20セリフ | スラムダンク(鎌倉高校前), ラブライブ!(神田明神) |

## 8. 制約事項

### 8.1 技術的制約

| 項目 | 制約 |
|------|------|
| 実行環境 | XAMPP (ローカル開発環境)。本番デプロイは別途検討 |
| PHP バージョン | 8.2.12 |
| DB | MariaDB 10.4.32 |
| フレームワーク | Laravel 11.x |
| 認証パッケージ | Laravel Breeze + Sanctum |
| フロントエンド | Blade + Vue 3 + Vite |

### 8.2 運用上の制約

| 項目 | 制約 |
|------|------|
| 著作権 | セリフの引用は著作権法の「引用」要件を満たす範囲で。出典の明記を必須とする |
| モデレーション | 投稿はすべて管理者承認制。不適切コンテンツの事前防止 |
| Nominatim API | レート制限 (1秒1回)。キャッシュで対応 |

## 9. 用語集

| 用語 | 説明 |
|------|------|
| セリフ (Quote) | 映画・アニメなどの作品から引用された台詞・名言 |
| 作品 (Work) | セリフの出典となる映画・アニメ・ドラマ・小説・ゲーム等 |
| 場所 (Location) | セリフに紐づく地理的な位置情報 |
| ピン (Pin/Marker) | 地図上に表示される場所のマーカー |
| クラスタリング | 近接するピンをまとめて数字付きアイコンで表示する機能 |
| バウンディングボックス | 地図の表示範囲を示す矩形領域 (北端・南端・東端・西端の緯度経度) |
| 聖地巡礼 | 作品の舞台やモデルとなった場所を訪れること |
| ポップアップ | ピンクリック時に地図上に表示される小さな情報ウィンドウ |
| モデレーション | 管理者がユーザー投稿を審査・管理すること |
