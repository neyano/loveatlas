## 2. 画面別詳細設計

### S-001: ホーム画面 (地図ビュー)

| 項目 | 内容 |
|------|------|
| URL | `/` |
| 認証 | 不要 |
| 概要 | アプリのメイン画面。地図とセリフ一覧の分割表示 |

#### 構成要素

| # | 要素 | 説明 |
|---|------|------|
| 1 | ヘッダー | ロゴ、検索バー、Explore リンク、ログイン/ユーザーメニュー |
| 2 | サイドパネル (PC) | フィルター、セリフカード一覧、投稿ボタン |
| 3 | ボトムシート (モバイル) | セリフカード一覧、投稿ボタン (ドラッグで展開) |
| 4 | 地図エリア | Leaflet 地図、ピン、クラスタ、ポップアップ |
| 5 | フィルター | 作品タイプ (映画/アニメ/ドラマ/全て)、ソート (人気/新着) |

#### イベント・動作

| イベント | 動作 |
|---------|------|
| ページ読込 | Leaflet初期化、日本中心で表示、バウンディングボックスAPIを呼び出しピン表示 |
| 地図移動/ズーム | 300msデバウンス後、新しい表示範囲でAPIを再呼び出し、ピンを更新 |
| ピンクリック | ポップアップ表示 (セリフ冒頭、作品名、いいね数、「詳細→」リンク) |
| ポップアップ「詳細→」クリック | セリフ詳細ページ (S-002) に遷移 |
| サイドパネルのセリフカードクリック | 地図をその場所にパン+ポップアップ表示 |
| フィルター変更 | APIを再呼び出し、ピンを再描画 |
| 「+投稿」ボタン | セリフ投稿ページ (S-003) に遷移 (未ログインならS-009) |

### S-002: セリフ詳細画面

| 項目 | 内容 |
|------|------|
| URL | `/quotes/{id}` |
| 認証 | 不要 (いいね等のアクションは要認証) |
| 概要 | セリフの全情報を表示 |

#### 構成要素

| # | 要素 | 説明 |
|---|------|------|
| 1 | セリフ引用ブロック | セリフ本文 (大きなフォント、引用デザイン) |
| 2 | キャラクター名 | 「── キャラクター名」形式 |
| 3 | 作品情報 | 作品名 (リンク)、公開年、作品タイプバッジ |
| 4 | 場所情報 | 場所名、住所、地図リンク |
| 5 | アクションバー | いいね、お気に入り、シェア、通報 |
| 6 | シーン説明 | 投稿者によるシーンの説明文 |
| 7 | ミニマップ | 小さなLeaflet地図にピン1つ |
| 8 | タグ | 紐づくタグのリスト (クリックでタグ一覧へ) |
| 9 | 投稿者情報 | アバター、表示名、投稿日 |
| 10 | 関連セリフ | 同じ場所のセリフ、同じ作品のセリフ (各3件) |

#### イベント・動作

| イベント | 動作 |
|---------|------|
| いいねボタン | POST /api/v1/quotes/{id}/vote → カウント更新 |
| お気に入りボタン | POST /api/v1/favorites → トグル |
| 場所名クリック | ホームの地図をその位置にフォーカスして遷移 |
| 作品名クリック | 作品詳細ページ (S-005) に遷移 |
| タグクリック | タグ別一覧ページ (S-008) に遷移 |
| 通報ボタン | 通報理由選択モーダル表示 → API送信 |

### S-003: セリフ投稿画面

| 項目 | 内容 |
|------|------|
| URL | `/quotes/new` |
| 認証 | 必須 |
| 概要 | セリフを投稿するフォーム |

#### 構成要素

| # | 要素 | 種別 | バリデーション |
|---|------|------|-------------|
| 1 | セリフ本文 | textarea | 必須, 1-2000文字 |
| 2 | 作品選択 | オートコンプリート入力 | 必須, 既存作品 or 新規登録 |
| 3 | キャラクター名 | text input | 任意, 最大200文字 |
| 4 | シーン説明 | textarea | 任意, 最大5000文字 |
| 5 | 話数情報 | text input | 任意, 最大100文字 |
| 6 | 場所検索 | text input + 検索ボタン | Nominatimで住所検索 |
| 7 | 地図 (位置選択) | Leafletミニマップ | 必須 (クリックで緯度経度取得) |
| 8 | 選択位置表示 | 読取専用テキスト | 緯度・経度の表示 |
| 9 | タグ選択 | タグ入力 (チップ表示) | 任意, 最大10個 |
| 10 | 画像 | ファイル入力 | 任意, jpg/png/webp, 最大5MB |
| 11 | プレビューボタン | button | 入力内容のプレビュー表示 |
| 12 | 投稿ボタン | submit button | POST /api/v1/quotes |

#### イベント・動作

| イベント | 動作 |
|---------|------|
| 作品入力 (3文字以上) | GET /api/v1/works/search?q= でオートコンプリート表示 |
| 「作品が見つからない」クリック | 作品新規登録モーダル表示 |
| 住所検索実行 | Nominatim APIで緯度経度取得 → 地図にピン表示 |
| 地図クリック | クリック位置の緯度経度を取得 → ピン移動 → リバースジオコーディング |
| プレビュー | 入力内容をセリフカード形式でプレビュー表示 |
| 投稿 | バリデーション → API送信 → 成功時「承認待ち」メッセージ表示 |

## 3. 共通コンポーネント

### 3.1 ヘッダー (partials/header.php)

```
PC:
[Logo] LoveAtlas     [________検索バー________]  [Explore]  [ログイン]
                                                             or
[Logo] LoveAtlas     [________検索バー________]  [Explore]  [👤 田中▼]

モバイル:
[☰]  LoveAtlas                                   [🔍]  [👤]
```

| 要素 | 未ログイン | ログイン済み |
|------|-----------|------------|
| 右側 | 「ログイン」「登録」リンク | アバター+名前のドロップダウン (プロフィール/設定/ログアウト) |

### 3.2 セリフカード (partials/quote-card.php)

```
┌────────────────────────────────┐
│ 「セリフ本文...」               │  ← 最大3行、省略記号
│                                │
│ 🎬 作品名 / キャラクター名      │  ← 作品名はリンク
│ 📍 場所名                      │  ← 場所名はリンク
│                                │
│ ♡ 42   投稿者名    2日前       │  ← いいね数・投稿者・日時
│ ● anime                       │  ← 作品タイプバッジ (色付き丸)
└────────────────────────────────┘
```

### 3.3 ページネーション (partials/pagination.php)

```
[← 前] [1] [2] [3] ... [10] [次 →]
```

### 3.4 トースト通知 (components/toast.js)

```
成功: 緑背景「✓ お気に入りに追加しました」
エラー: 赤背景「✗ エラーが発生しました」
情報: 青背景「ℹ 投稿は管理者の承認後に公開されます」
位置: 画面右上、3秒後に自動消滅
```

### 3.5 モーダル (components/modal.js)

- 背景オーバーレイ (半透明黒)
- 中央配置のダイアログボックス
- 閉じるボタン (右上 ×) + 背景クリックで閉じる
- 用途: 作品新規登録、通報理由入力、確認ダイアログ
