# LoveAtlas - プロジェクト概要

## 1. アプリケーション概要

**LoveAtlas** は、地図上の場所と映画・アニメの名セリフを結びつけるコミュニティ駆動型Webアプリケーションです。

ユーザーは地図上の場所をクリックし、その場所に関連する作品のセリフを閲覧・投稿できます。旅行計画や聖地巡礼の際に、作品の言葉が新しい視点を提供します。

### コンセプト

> 地図上で場所を選ぶと、その土地にまつわる映画やアニメの名言が表示される。
> 旅行の計画中や、訪れた場所で、作品の言葉が新しい視点をくれる。

### このアプリのユニークさ

1. **物語と場所の交差点** - 単なる聖地巡礼マップではなく、「場所にセリフが息づく」体験を提供
2. **コミュニティ駆動** - ユーザー自身がコンテンツを育てる投稿・いいね・キュレーションのサイクル
3. **感情の地図** - ピンが単なる位置情報ではなく「感情」を持つ。セリフを通じて場所に物語的な意味を付与
4. **旅行計画の新しい視点** - 「この街にはこんなセリフがある」という発見が旅行のモチベーションに

## 3. 機能一覧 (MVP)

| # | 機能 | 優先度 | 説明 |
|---|------|--------|------|
| F1 | インタラクティブ地図 | 必須 | Leaflet + OSM でセリフのピンを表示。クラスタリング対応 |
| F2 | セリフ閲覧 | 必須 | ピンクリックでポップアップ表示 → 詳細ページへ遷移 |
| F3 | ユーザー認証 | 必須 | メール+パスワード。登録/ログイン/ログアウト/パスワードリセット |
| F4 | セリフ投稿 | 必須 | セリフ・作品・キャラ・場所を紐付けて投稿 |
| F5 | いいね | 必須 | セリフへのいいねトグル |
| F6 | お気に入り | 必須 | セリフのブックマーク保存 |
| F7 | 訪問記録 | 必須 | 場所を「訪問済み」としてマーク (日付・メモ・評価付き) |
| F8 | 検索 | 必須 | セリフ・作品・場所の横断検索 |
| F9 | 作品ページ | 必須 | 作品に紐づくセリフ一覧 |
| F10 | プロフィール | 必須 | 投稿・お気に入り・訪問履歴の閲覧 |
| F11 | モデレーション | 必須 | 管理者によるセリフ承認/拒否・通報管理 |
| F12 | バウンディングボックス取得 | 必須 | 地図表示範囲内のセリフのみAPI取得 |

### 地図ピン表示戦略

- **クラスタリング**: ズームレベルに応じた自動クラスタリング (Leaflet.markercluster)
- **色分け**: 作品タイプで視覚的に区別
  - 映画 = 青、アニメ = 赤、ドラマ = 緑、その他 = 灰
- **ポップアップ**: セリフ冒頭、作品名、いいね数、「詳細を見る」リンク
- **位置選択 (投稿時)**: 地図クリック or Nominatim住所検索 (無料)
